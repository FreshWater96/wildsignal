# Wildsignal

A complete browser game built with Three.js and locally bundled CC0 scanned materials.

Serve `dist/` with a static HTTP server. No installation or build step is needed.

The player explores the basin, restores three relays, avoids storm wisps, gathers
lumen flowers, drops echo lures, and returns to Base Camp for rescue. Expedition
mode has an eight-minute deadline. Wander mode disables damage and the deadline.

The scene includes procedural terrain and forest, photogrammetry ferns and mossy
rocks, a river with two bridges, waterfall, camp, relay monuments, fireflies,
dynamic atmosphere, synthetic Web Audio, a survey map, local saves, and touch input.

This is an original adaptation of the wilderness concept. It does not embed Unreal
Engine or any Electric Dreams assets. See `dist/credits.txt` for source attribution.
